Asistente virtual de estadística aplicada

Ejecutar:   pip install -r requirements.txt
            streamlit run app.py

Datos de la portada (nombres, asignatura, sección): primeras líneas de app.py.
Comprobar los cálculos sin abrir la app:  python pruebas.py

Archivos
  app.py            interfaz y pestañas
  utils.py          lectura y validación de datos
  descriptiva.py    media, mediana, moda, rango, varianza y desviación
  experimental.py   mediciones con unidades y conversiones
  tablas.py         tabla de frecuencias e histograma
  probabilidad.py   probabilidad básica y distribución normal
  regresion.py      correlación, regresión lineal y diagrama de dispersión
  interpretacion.py desviación poblacional vs. muestral
  practicas.py      ejemplos resueltos y generador de prácticas
  ayudas.py         formato, validación y presentación de resultados
  pruebas.py        pruebas con valores conocidos
